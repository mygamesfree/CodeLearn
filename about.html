    About CodeLearn

    A free, beginner-first path into web development.

    What is CodeLearn?

    CodeLearn is a small learning platform that teaches the three languages of the web — HTML, CSS and JavaScript — through short lessons, editable live examples, checked exercises and guided projects. Every lesson is written for people who have never written a line of code before.

    How it works

    1. Read a lesson with clear explanations and code samples.
    2. Play with the live playground: edit the code and watch it update.
    3. Practise the exercise and get instant feedback with a score.
    4. Build a project with clear requirements and completion criteria.
    5. Track your progress on your dashboard, saved lesson by lesson.

    Accounts and your data

    You can use every lesson and exercise without an account — progress is stored in your browser. If you create an account (powered by Supabase), your progress syncs to your account so it follows you across devices. Course content stays completely free.

    The tech behind it

    No frameworks and no build step: the whole site is hand-written HTML5, CSS3 and vanilla JavaScript modules, which makes the source a learning resource in its own right. Peek at the page source — you are welcome to learn from it.

    Your feedback mattersFound a mistake in a lesson? The project is built to be easy to improve: all content lives in one file, js/data.js.
